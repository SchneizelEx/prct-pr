# ระบบติดตามการออกประชาสัมพันธ์รับนักเรียนใหม่

ระบบเว็บสำหรับจัดสายออกแนะแนวประจำวัน มอบหมายบุคลากรหลายคนต่อสาย เลือกโรงเรียนเป้าหมายได้หลายแห่งต่อสาย และให้บุคลากรรายงานผลการแนะแนวแต่ละโรงเรียนด้วยรูปถ่าย 1 รูป พร้อมจำนวนนักเรียนที่สนใจ (ม.2, ม.3, ม.5, ม.6)

## สแตก

- PHP 8.3 (plain PHP, PDO, ไม่ใช้เฟรมเวิร์ก)
- MySQL 8.4
- Bootstrap 5 (ผ่าน CDN)

## โครงสร้างข้อมูล

- `staff` — บุคลากร (เป็นทั้งข้อมูลบุคลากรและบัญชีผู้ใช้: `username`, `password_hash`, `role` = `admin`/`staff`)
- `schools` — โรงเรียนเป้าหมาย (มี `latitude`/`longitude`)
- `outreach_lines` — สายออกแนะแนวต่อวัน
- `line_staff` — บุคลากรที่ประจำแต่ละสาย (many-to-many)
- `line_schools` — โรงเรียนที่แต่ละสายไปเยือน (many-to-many, 1 สาย → หลายโรงเรียน)
- `visit_reports` — รายงานผล 1 รายการต่อ 1 โรงเรียนในสาย (รูปถ่าย 1 รูป + จำนวนนักเรียนแต่ละชั้น)

ดู [database/schema.sql](database/schema.sql) สำหรับ DDL ฉบับเต็ม

## สิทธิ์ผู้ใช้งาน

ทุกหน้าในระบบต้องล็อกอินก่อนใช้งาน (`public/login.php`) มี 2 สิทธิ์:

| สิทธิ์ | เข้าถึงได้ |
|---|---|
| **ผู้ดูแลระบบ (admin)** | ทุกอย่าง — จัดการบุคลากร/โรงเรียน/สาย ตั้งบัญชีผู้ใช้และรหัสผ่านให้บุคลากร ดูรายงานทั้งหมด |
| **บุคลากร (staff)** | ดูเฉพาะสายที่ตัวเองถูกมอบหมาย บันทึกรายงาน (รูป+จำนวนนักเรียน) เฉพาะโรงเรียนในสายของตัวเอง ดูรายชื่อโรงเรียนทั้งหมดได้ (อ่านอย่างเดียว) |

บัญชีเริ่มต้นที่สร้างไว้ให้ (**ควรเปลี่ยนรหัสผ่านทันทีหลังติดตั้งจริง**):

| Username | Password | สิทธิ์ |
|---|---|---|
| `admin` | `Admin@2026` | ผู้ดูแลระบบ |

บุคลากรคนอื่น ๆ ที่เพิ่มในหน้า "บุคลากร" จะยังไม่มีบัญชีผู้ใช้จนกว่าแอดมินจะกดปุ่มรูปกุญแจ 🔑 ที่แถวนั้นเพื่อตั้งชื่อผู้ใช้/รหัสผ่าน/สิทธิ์ให้

## ฐานข้อมูลโรงเรียน (พิกัดละติจูด/ลองจิจูด)

นำเข้าโรงเรียนทั่วประเทศไทยพร้อมพิกัดจาก **OpenStreetMap (Overpass API)** ไว้ล่วงหน้า **11,539 แห่ง** ทุกแห่งมีชื่อและพิกัด บางแห่งมีอำเภอ/จังหวัด/เบอร์โทรด้วย (ข้อมูลจากผู้ใช้ OSM ทั่วโลกจึงมีความครบถ้วนไม่เท่ากัน — เป็นข้อมูลทุกระดับชั้น ไม่ได้กรองเฉพาะมัธยม และอาจมีบางรายการซ้ำ/ไม่เกี่ยวข้อง เช่นชื่อทดสอบที่หลุดเข้ามาจากผู้ใช้ OSM ที่แก้ไขผิด ลบออกได้ที่หน้า "โรงเรียน")

ในหน้า **โรงเรียน** และตอน **ตั้งสายใหม่** จึงเปลี่ยนจากรายการ checkbox (ซึ่งใช้ไม่ได้จริงกับข้อมูลระดับหมื่นแถว) เป็นช่องค้นหาแบบพิมพ์แล้วเลือก (พิมพ์อย่างน้อย 2 ตัวอักษร) — ดูโค้ดที่ `public/school_search.php` (API ค้นหา) และ `public/assets/school-picker.js` (วิดเจ็ต)

หากต้องการนำเข้าข้อมูลใหม่ซ้ำ (เช่นอัพเดทพิกัด) ใช้สคริปต์:
```bash
php database/import_osm_schools.php <path-to-osm-overpass.json>
```

## การติดตั้ง

1. สร้างฐานข้อมูลและตาราง:

   ```bash
   mysql -u root -p < database/schema.sql
   ```

2. ตั้งค่าการเชื่อมต่อฐานข้อมูล — แก้ไข [config/database.php](config/database.php) โดยตรง หรือกำหนด environment variable ก่อนรัน:

   - `DB_HOST` (ค่าเริ่มต้น `127.0.0.1`)
   - `DB_PORT` (ค่าเริ่มต้น `3306`)
   - `DB_NAME` (ค่าเริ่มต้น `prct_pr`)
   - `DB_USER` (ค่าเริ่มต้น `root`)
   - `DB_PASS`

3. รันเซิร์ฟเวอร์สำหรับพัฒนา (document root คือโฟลเดอร์ `public/`):

   ```bash
   php -S localhost:8000 -t public
   ```

   เปิดเบราว์เซอร์ที่ `http://localhost:8000`

4. สำหรับใช้งานจริงบน Apache/Nginx: ชี้ document root ไปที่ `public/` เท่านั้น (ห้ามชี้ไปที่โฟลเดอร์โปรเจกต์ทั้งหมด เพราะ `config/`, `includes/`, `database/` ไม่ควรเข้าถึงได้จากเว็บ) และตรวจสอบว่า `public/uploads/` เขียนได้ (permission)

## หน้าที่มีในระบบ

| หน้า | ไฟล์ | หน้าที่ |
|---|---|---|
| ล็อกอิน / ออกจากระบบ | `public/login.php`, `public/logout.php` | เข้า/ออกระบบด้วย username + password |
| แดชบอร์ด | `public/index.php` | สรุปภาพรวม สายที่จะมาถึง โรงเรียนที่ค้างรายงาน ยอดนักเรียนสะสม (บุคลากรเห็นเฉพาะสายของตัวเอง) |
| สายแนะแนว | `public/lines.php` | ตั้งสายใหม่ (แอดมินเท่านั้น) และดูรายการสาย (บุคลากรเห็นเฉพาะสายของตัวเอง) |
| รายละเอียดสาย | `public/line_detail.php` | ดูบุคลากร/โรงเรียนในสาย อัพเดทสถานะ — เพิ่ม/ลบโรงเรียนได้เฉพาะแอดมิน |
| บันทึกรายงาน | `public/report_form.php` | อัพโหลดรูปถ่าย 1 รูป + จำนวนนักเรียน ม.2 ม.3 ม.5 ม.6 ต่อ 1 โรงเรียน (ผู้รายงาน = ผู้ที่ล็อกอินอยู่ ต้องอยู่ในสายนั้น) |
| บุคลากร | `public/staff.php` | CRUD บุคลากร + ตั้งค่าบัญชีผู้ใช้/รหัสผ่าน/สิทธิ์ (แอดมินเท่านั้น) |
| โรงเรียน | `public/schools.php` | ค้นหา/แบ่งหน้าโรงเรียนเป้าหมาย (แอดมินเพิ่ม/แก้ไข/ลบได้ บุคลากรดูอย่างเดียว) |
| รายงานผล | `public/reports.php` | ดูรายงาน กรองตามวันที่/โรงเรียน สรุปยอดรวมแต่ละชั้น (บุคลากรเห็นเฉพาะรายงานของสายตัวเอง) |
| ค้นหาโรงเรียน (API) | `public/school_search.php` | คืนผลค้นหาแบบ JSON ให้วิดเจ็ตเลือกโรงเรียนใช้ |

## หมายเหตุการออกแบบ

- รายงานผูกกับคู่ (สาย, โรงเรียน) ไม่ใช่ผูกกับสายทั้งก้อน เพราะจำนวนนักเรียนที่สนใจย่อมต่างกันในแต่ละโรงเรียนแม้อยู่สายเดียวกัน
- ระบบสิทธิ์ผูกกับตาราง `staff` โดยตรง (ไม่มีตาราง users แยก) — บุคลากรทุกคนเป็นทั้ง "ข้อมูลบุคลากร" และ "บัญชีผู้ใช้" ในแถวเดียวกัน ทำให้ `reported_by` ในรายงานอ้างอิงกับผู้ล็อกอินอยู่ได้ตรงไปตรงมา
- รูปถ่ายถูกจำกัดชนิดไฟล์ (JPG/PNG/WEBP) ขนาดไม่เกิน 8MB และปิดการรันสคริปต์ในโฟลเดอร์ `uploads/` ด้วย `.htaccess`
- ข้อมูลโรงเรียนระดับหมื่นแถวทำให้ checkbox list ใช้ไม่ได้จริง จึงเปลี่ยนทุกจุดที่ต้องเลือกโรงเรียนเป็นช่องค้นหา (debounced fetch ไป `school_search.php`) แทน — รวมถึง dropdown กรองในหน้ารายงานที่จำกัดเหลือเฉพาะโรงเรียนที่เคยถูกกำหนดในสายจริงเท่านั้น ไม่ดึงทั้งฐานข้อมูล
